Woxsenite is a web-based platform that rewards students for academic and extracurricular participation using blockchain-based tokens.

-Students can earn tokens by:
-Marking attendance
-Participating in hackathons
-Uploading certifications
-Participating in sports or club activities
-These tokens are minted on a blockchain and tracked through a student dashboard. The system also uses an AI-based certificate verification module to reduce fraudulent submissions.


Key Features

-Student dashboard to track tokens and activities
-Attendance-based token rewards
-Event submission with certificate upload
-AI certificate verification using OCR
-Admin approval system
-Blockchain token minting
-Transaction history tracking
-Token wallet for each student
